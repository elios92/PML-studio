# PML Studio

Editor nativo Windows per la creazione e conversione di fangame Pokémon.

## Sorgente ufficiale

La baseline di sviluppo corrente è PML Studio 5.1.0. Il repository segue il Master Development Plan: stabilità prima delle nuove funzioni, collegamento ai dati reali, test e regressione prima del congelamento.

## Aggiornamenti

Le build installabili devono essere distribuite esclusivamente tramite GitHub Releases verificate. L'applicazione non deve aggiornarsi direttamente dal ramo main.

Repository inizializzato il 23 settembre 2026.
